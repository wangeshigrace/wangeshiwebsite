The story

How it happened

It wasn't planned. It started with curiosity and a lot of late nights.

🌱

The beginning

I was bored and curious

I stumbled onto ChatGPT and started asking random questions. I didn't know it would change everything. I just wanted to see what it could do.

💻

First experiment

I asked it to teach me HTML

I typed "teach me how to build a website from scratch" and it actually did. Step by step. I built my first page that same week. It was ugly — but it worked.

🎨

Getting creative

Design, logos, graphics

I found Canva AI and Deep AI for visuals. I started designing brand assets, social media content, even logos — all with AI as my creative partner.

⚡

Level up

Cursor changed how I code

Cursor lets me write real code with AI inside the editor. I could build things I didn't fully understand yet — and learn by watching it happen in real time.

🌍

Today

Real work, real results

I've built websites for organisations, managed social media for brands, and created content that performs. AI didn't do it for me — it helped me do it better.
